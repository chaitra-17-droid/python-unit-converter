# Python Unit Converter

A small Python project that converts units and is tested automatically using GitHub Actions.

## Features
- Celsius to Fahrenheit
- Kilometres to miles
- Kilograms to pounds

## Run the tests
```bash
pip install -r requirements.txt
pytest
```

## What I learned
- Creating branches and pull requests
- Linking an Issue to a pull request with `Closes #1`
- Running tests automatically with GitHub Actions
- Reading a failed workflow and fixing it
